# Repository Security Statement

## Intended Users and Data
- This repository is intended to be used by myself as a means to submit assignments for CSE 3000 (Contemporary Issues in Computer Science and Engineering). It is intended to be viewed exclusively by the professor, Matthew Lamoureux.

## Risk Assessment
- The security risk of this repository is minimal as it is solely academic work. The only possible risk is academic plagiarism if another student were to access my repository.

## Security Measures
This repository is very low risk and only used by one 'developer', so any security measures other than the following would be overkill:
- The repository is set to private.
- A standard .gitignore file is used.
- The CODEOWNERS file is kept from the original repository marking it as owned by the professor.
